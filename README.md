## 📋 Описание проекта

Проект представляет собой **4-этапную цепочку (Chain) на базе LangChain**, которая принимает текстовое описание задачи по веб-скрапингу и генерирует готовый, проверенный Python-скрипт.

### Архитектура цепочки

| Этап | Название | Описание |
|------|----------|----------|
| **1** | 🔍 **Анализ задачи** | ИИ выделяет целевой URL, данные для извлечения, оценивает сложность и наличие антибот-защиты |
| **2** | 🛠️ **Подбор инструментов** | Автоматический выбор оптимального стека: `requests`, `playwright`, `scrapy` и др. |
| **3** | 💻 **Генерация кода** | Создание полного исполняемого скрипта с обработкой ошибок и логированием |
| **4** | 🔎 **Статическое ревью** | Проверка синтаксиса через `ast.parse` + автоматическое исправление через LLM |

---

## ⚠️ Архитектурное решение: Локальный ИИ

Проект **спроектирован для работы с локальными языковыми моделями** через [Ollama](https://ollama.com/), что обеспечивает:

- **🔒 Независимость от сетевых ограничений** — стабильная работа в условиях региональной специфики сетевого доступа (Крым), где зарубежные облачные API (OpenAI, Anthropic) могут быть нестабильны или требовать обхода блокировок.
- **🚫 Отказ от инструментов обхода** — исключает необходимость в VPN/прокси, предотвращает конфликты ресурсов.
- **🛡️ Конфиденциальность** — данные не покидают локальную машину.
- **💰 Нулевые затраты** — отсутствие оплаты за API-токены.

- **Python 3.11+**
- **LangChain Core** — построение цепочек запросов
- **Ollama** — локальный сервер LLM с OpenAI-совместимым API
- **OpenAI Python Client** — взаимодействие с локальным API
- **python-dotenv** — загрузка переменных окружения
